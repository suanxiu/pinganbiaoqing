# pinganbiaoqing

平安表情银发表达小程序的产品与开发文档基线。

## 当前状态

本仓库包含平安表情银发表达小程序的产品文档与微信小程序原生代码。

## 当前开发状态

已完成第一版框架：

- 每日平安：首页默认推荐早安/晚安内容。
- 制作：选择照片、选择祝福语、保存本地草稿。
- 相册：查看、分享入口与删除本地草稿。
- 商城：分类和商品列表框架，暂不开放支付。
- 昨日新闻、经典旋律：二级页面和内容服务接口。
- 广告：默认关闭的适配层，不阻断保存与分享。

## P0 开发进度

已补齐静态成品闭环：默认卡/选图 -> Canvas 合成 -> 预览 -> 保存或分享 -> 相册恢复。动态照片目前保留任务状态和静态降级，待配置云端渲染服务后开启。

详见 `docs/2026-08-21-p0-implementation-notes.md`。

## 打开项目

1. 安装微信开发者工具。
2. 导入本仓库根目录，工具会读取 `project.config.json`。
3. 当前使用 `touristappid`，可直接查看本地框架；真机和正式能力需要替换为项目 AppID。

小程序源码位于 `miniprogram/`，框架设计见 `docs/2026-08-21-mini-program-framework-design.md`。

唯一开发基线：

- `平安表情小程序统一开发策划案_4.1.docx`
- `平安表情小程序详细开发规格书_3.1.docx`

## 产品原则

- 方便、简单、容易学，打开后直接得到可分享内容。
- 首发核心是早安/晚安动态照片、照片自动配字、保存和微信分享。
- 经典旋律/红歌只使用权利清晰的授权素材。
- 使用轻量托管后端、私有临时存储和异步媒体任务，不建设重型服务器。
- 广告接口保留并可远程关闭，默认不阻断保存和分享。
