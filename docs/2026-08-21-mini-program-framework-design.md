# 平安表情小程序框架设计

## 第一阶段目标

为 55-80 岁微信用户提供低学习成本的图片表达工具。首页先给当天可用的默认内容，不要求注册或设置，即可完成查看、制作、保存和分享。

## 范围与边界

- 四个主入口：每日平安、制作、相册、商城。
- 首页提供早安/晚安推荐、昨日新闻和经典旋律入口。
- 制作页支持选照片、选默认文案、保存本地草稿。
- 相册支持展示、分享入口和删除本地草稿。
- 商城只搭分类与商品列表，不接支付。
- 内容、媒体、广告均通过 services 适配，第一阶段使用本地演示数据。
- 不上传用户原图，不接真实 AI、新闻、音乐或视频服务。

## 体验与视觉

- 首页先给结果，再给选择；每屏只突出一个主要动作。
- 主要文字不小于 32rpx，按钮触控高度不小于 96rpx。
- 视觉方向：温暖编辑型，中式纸张和印章意象。
- 色板：宣纸白 `#FFF9EF`、朱砂红 `#B9342B`、松柏绿 `#2F6650`、墨色 `#28231F`、金黄 `#D9A441`。
- 单列信息流，首页主推荐跨满宽度，快捷入口采用不等宽双列。

## 技术边界

- 微信小程序原生 JavaScript/WXML/WXSS。
- `services` 隔离未来轻量云托管、AI、内容审核、媒体和广告实现。
- `utils/storage.js` 统一管理本地草稿。
- `config/env.js` 统一注入接口地址、广告位和功能开关。
- 后续后端只承载内容配置、临时媒体任务、审核状态和远程开关；用户原图默认本机处理。

## 验收

- 微信开发者工具能识别项目并打开四个主页面。
- 首页、制作、相册、商城能互相切换。
- 可选择本机照片并保存一条本地草稿。
- 相册能展示并删除草稿。
- 无后端、无广告位、无正式 AppID 时页面不崩溃。
