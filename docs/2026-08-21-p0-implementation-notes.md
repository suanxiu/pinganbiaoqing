# P0 开发记录

## 已实现

- 今日页按 05:00-11:59、17:00-23:59 和其他时间段选择场景；内容只接受 `approved + clear` 卡片。
- 本地默认精品卡、缓存回退和远程内容接口位已完成。远程接口未配置时不发网络请求，直接使用本地内容。
- 首次用户无需设置。偏好只有在主动选择达到 3 次且置信度达到 0.70 后，才允许进入默认排序；首页切换底图会记录为主动选择。
- 制作页完成选图、默认祝福语选择和预览导航。
- 预览页使用端侧 Canvas 合成静态 PNG：安全区裁切、五种装饰主题、自动换行和长文案截断。
- 保存图片处理首次授权、拒绝后的重新授权和失败文案；分享优先使用微信图片分享能力。
- 动态照片入口具备任务状态与静态降级：视频服务关闭或未配置时不创建外部任务，保留高清静态结果。
- 本地相册保存作品元数据和本地结果路径，不上传原图；埋点只记录白名单字段。

## 本轮未做

- 真正的云端视频渲染、AI 生成、新闻审核后台、版权音乐曲库、商城订单和支付。
- 这些能力继续通过 `services` 和 `config/env.js` 接口接入，不能直接在页面里硬编码。

## P0 验收路径

1. 首页点击默认卡，生成一张无照片问候图。
2. 制作页选一张照片，选择文案，进入预览。
3. 预览页保存到手机，相册权限拒绝后能重新打开设置。
4. 预览页分享；不支持图片直分享时提示先保存。
5. 点击动态照片，视频服务未配置时显示静态回退，不丢失成品。
6. 进入相册可看到已保存成品并删除。
